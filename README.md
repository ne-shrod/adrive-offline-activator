## Состав проекта

### `detours.h`
Заголовочный файл библиотеки **Microsoft Detours**. Содержит объявления API
для перехвата функций (`DetourTransactionBegin`, `DetourAttach`, `DetourDetach`
и т.д.). Нужен на этапе компиляции `hook.cpp`. Версия — 4.x (совместима с
текущим кодом).

### `detours.lib`
Скомпилированная библиотека **Microsoft Detours** для линковки. Содержит
реализацию функций перехвата. Подключается к `hook.dll` через
`#pragma comment(lib, "detours.lib")`.

### `hook.cpp`
Исходник **внедряемой DLL** (`hook.dll`). Что делает:
- перехватывает `SysAllocString` из `oleaut32.dll` через Detours;
- при вызове в целевом процессе спрашивает у supervisor'а (через named pipe),
  надо ли подменить строку;
- если надо — возвращает подменённое значение вместо оригинала.

Именно этот файл отвечает за **подмену HWID** на уровне WMI/COM-строк.

### `main.cpp`
Исходник **supervisor'а** (основной exe). Что делает:
- собирает реальные HWID (BIOS, CPU, диск) через WMI;
- строит таблицу замен «реальный → фейковый»;
- поднимает named pipe для общения с `hook.dll`;
- находит процесс `PDDTests.exe`, инжектит в него `hook.dll`;
- через pipe отвечает DLL'ке, какие строки на какие менять.

Точка входа проекта — этот файл.

### `flask-server.py`
Локальный **fake-сервер активации** на Flask. Что делает:
- слушает порт 80 (или 8000) и принимает SOAP-запросы от adrive;
- на `CheckForUpdate` отвечает пустым `<CheckForUpdateResult/>`;
- на `Activate` с нужным `unc` возвращает лицензионный ключ
  в теге `<a:Code>`;
- на всё остальное отдаёт SOAP Fault.

Используется в **офлайн-режиме** вместе с подменой `hosts`, чтобы завернуть
трафик `activation.adrive.by` на локальную машину.

---

## Как это работает вместе

1. В `hosts` прописывается `127.0.0.1 activation.adrive.by` — трафик adrive
   уходит не на реальный сервер, а на локальный Flask.
2. Запускается `flask-server.py` — он отвечает на SOAP-запросы программы
   так, как это делал бы настоящий сервер активации.
3. Запускается `main.cpp` (supervisor) — он инжектит `hook.dll` в
   `PDDTests.exe` и подменяет HWID, чтобы программа видела «правильное»
   железо.
4. `PDDTests.exe` при старте стучится на «сервер» (Flask), получает
   корректный ответ и проходит активацию офлайн.

## Зависимости

- **Microsoft Detours 4.x** (`detours.h`, `detours.lib`)
- **Visual Studio** (MSVC, C++17) — для сборки `hook.cpp` и `main.cpp`
- **Python 3.8+** и **Flask** — для `flask-server.py`
- **Windows 10/11** (x64)

## Запуск (офлайн-режим)

1. Собрать `hook.dll` и `main.exe` (оба x86) или скачать готовые из Releases.
2. Добавить от имени администратора в `C:\Windows\System32\drivers\etc\hosts` строку:

   ```
   127.0.0.1  activation.adrive.by
   ```
   
3. Если это первый запуск запустите `flask-server.py` или готовый `flask-server.exe` из Releases.
4. Запустить `main.exe`.
5. Запустить `PDDTests.exe` — активация пройдёт офлайн.
